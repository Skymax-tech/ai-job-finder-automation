# AI Job Finder Automation

## 📌 Project Overview

An AI-powered job search workflow designed to help users find relevant job opportunities based on their preferred role and country.

The workflow collects the user's job preferences, stores the request in Airtable, searches for available job opportunities, uses AI to identify the most suitable options, sends personalized recommendations by email, and stores the recommendations for future reference.

## 🔄 Workflow

User submits job search request
↓
Name, email, preferred role, and country captured
↓
Search request saved to Airtable
↓
Relevant job opportunities retrieved
↓
Job information sent to AI
↓
AI recommends the 3 best opportunities
↓
AI explains why each opportunity is suitable
↓
Recommendations emailed to the user
↓
Recommendations stored in Airtable

## 🤖 AI Recommendations

The AI reviews the available job opportunities and selects the three options that best match the user's preferences.

Each recommendation includes an explanation of why the opportunity may be suitable for the user.

## 🛠️ Tools & Platforms

- n8n
- Airtable
- Google Gemini AI
- Gmail
- Job search API / mock job data

## 🔔 Automation Notification

The workflow can also notify a team through Slack whenever a new job search request is submitted.

## 🎯 Business Value

This automation can help:

- Reduce manual job-search effort
- Personalize job recommendations
- Organize job-search requests
- Deliver recommendations automatically
- Keep recommendation records in Airtable
- Reduce repetitive administrative work

## 🔐 Privacy & Security

This repository contains a portfolio demonstration of the workflow.

No real user information, passwords, API keys, authentication credentials, or private business data are included.
